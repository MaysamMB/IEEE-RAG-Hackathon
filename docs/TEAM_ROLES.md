# Initial Team Roles — Three Members

These are suggested primary ownership areas, not silos. Every member should understand the full RAG pipeline.

## Member A — Data and Retrieval
- Inspect permitted source documents
- PDF/text extraction and preprocessing
- Chunking and metadata strategy
- Embedding model comparison
- ChromaDB indexing and retrieval
- Retrieval tests and evidence

## Member B — Backend and Generation
- Python application structure
- LLM integration and prompt design
- Grounding and refusal behavior
- Source/page citation mapping
- Error handling and configuration
- Integration with the user interface

## Member C — Product, Evaluation, and Pitch
- Arabic (RTL) user interface and usability
- Build benchmark questions with expected evidence
- Run evaluation with Members A/B
- README, demo script, and presentation
- Market research, pricing assumptions, marketing plan

## Shared responsibilities
- Agree on the problem and scope
- Review architecture and trade-offs
- Test the live application
- Rehearse the demo and judge Q&A
- Keep secrets and private data out of Git
